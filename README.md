# 夏渝乔的个人主页

暖色调、衬线排版的静态学术主页，适用于 GitHub Pages。纯 HTML + CSS，无需构建。

## 设计

- **配色**：象牙白底 `#faf9f5`，墨色正文 `#141413`，陶土色点缀 `#c96442` / `#d97757`。系统为深色模式时自动切换为暖炭色。
- **字体**：中文 Noto Serif SC，英文 Newsreader（均来自 Google Fonts，加载失败时回退到宋体 / Georgia）。导航和按钮使用系统无衬线字体。
- **印章**：首页右上角的「夏渝乔印」是页面唯一的强调元素，载入时有一次盖章动画（系统开启“减少动态效果”时不播放）。
- **版式**：左侧中文标题 + 英文斜体副标题，右侧内容，行宽控制在 36rem 以内；手机端改为单栏。

## 修改内容

- `index.html`：姓名、简介、教育、研究方向、论文、项目和链接。每个待补充位置都留有 HTML 注释和格式示例。
- `styles.css`：顶部 `:root` 里是全部颜色与字体变量，改主题色只需改这里。

目前只填写了已确认的信息：夏渝乔、西南大学、计算机科学与技术。研究、论文、项目三栏显示“正在整理，稍后更新”。补充内容时，把对应注释里的示例复制出来替换即可；不准备展示的栏目可以整段删除对应 `section`，并删除顶部导航里的链接。

## 本地查看

直接用浏览器打开 `index.html`。

## 发布

提交并推送到 `YuqiaoXia/yuqiaoXia.github.io` 的 `main` 分支后，在仓库 Settings → Pages 中选择从 `main` 分支的 `/(root)` 部署。地址为 https://yuqiaoxia.github.io/。
